# SnowClient releases

Official distribution repository for SnowClient Rust Edition. The source repository is maintained separately and remains private.

Releases provide:

- `SnowClient-Setup.exe`: Windows x64 installer, including the game.
- `snowclient-windows-x64.zip`: game package used by the launcher.
- `SHA256SUMS` and `SHA256SUMS.sig`: SHA-256 checksums and their Ed25519 signature.

The launcher verifies signed checksums before installing downloaded game packages. Minecraft game files, account data, and signing secrets are not distributed here. Playing requires your own Minecraft: Java Edition account and locally prepared resources.
